# TrebuchetController 接口与接线规范

-   文档版本：v1.0（第一阶段草案）
-   控制板：Arduino Uno R3（5 V logic）
-   当前已知传感器：数字输出型红外传感器（VCC / GND / OUT 或 DO）
-   当前阶段：传感器监测、状态指示、软件故障锁定与独立硬件验证
-   **本规范不定义自动装填、解锁或发射动作。**

> 重要：这是建议的统一接口分配。接线前必须核对实物模块上的引脚标识、额定电压和舵机型号。若实际硬件与本文不同，以实物规格为准并先更新本文，不要盲接。

## 1. 接线总原则

1.  **先断电接线**：拔掉 Arduino USB 和外部电源后再改线。
2.  **先接传感器，后接舵机**：第一轮测试只接
    Arduino、红外传感器和状态指示灯。
3.  **共地**：使用独立舵机电源时，舵机电源 GND 必须与 Arduino GND
    共地；舵机正电源不要接到 Arduino 5V。
4.  **禁止用 Uno 的 5V
    引脚给多个舵机供电**：舵机启动/堵转电流可能导致板子复位、USB
    过流或损坏。使用符合舵机电压和电流要求的独立稳压电源。
5.  **软件停止不等于硬件断电**：Arduino 的停止命令、LED
    或舵机信号都不能替代能切断执行器电源的实体急停/断电装置。机械储能也必须单独处理。
6.  **不要让传感器输入悬空**：按本规范使用明确的输入接法；如果模块输出类型不是普通推挽数字输出，应先确认是否需要上拉。
7.  **先验证极性**：红外模块检测到物体时可能输出 LOW，也可能输出
    HIGH。先观察串口原始电平，再设置软件有效电平。

### 引脚使用说明

-   D0、D1 留给 USB 串口通信，避免连接外设影响上传和串口诊断。
-   D2 用作当前红外数字输入，软件配置为 `kInfraredPin = 2`。
-   D3、D4 的按钮是**软件命令输入**，不是安全认证的硬件急停。
-   D5、D6、D9 是未来独立舵机测试的信号引脚预留。当前固件不驱动舵机。
-   D10--D12 是普通数字输出状态灯预留。每颗 LED 都必须串联限流电阻。
-   若未来添加更多传感器，必须先更新本表，避免重复占用引脚。

## 3. 红外传感器接线（当前必接）

常见三针数字红外模块：

  模块标识   连接到 Uno R3                说明
  ---------- ---------------------------- --------------
  VCC        5V（仅当模块明确支持 5 V）   供电
  GND        GND                          地线
  OUT / DO   D2                           数字信号输入

接线步骤：

1.  拔掉 Arduino USB。
2.  根据 PCB 丝印辨认 VCC、GND、OUT/DO，不要仅凭线色判断。
3.  确认模块额定电压后连接 VCC 和 GND。
4.  将 OUT/DO 接到 D2。
5.  检查没有短路或接反，再接 USB。
6.  打开 115200 baud 串口监视器，分别记录无遮挡与遮挡时的
    `raw=HIGH/LOW`。
7.  根据实测结果设置 `kInfraredActiveLevel`。不要假定所有模块都是 LOW
    有效。

如果输出一直不变：先检查供电、地线、引脚顺序、模块电位器/指示灯及检测距离；不要马上判断传感器损坏。

## 4. 按钮接线（后续实现时启用）

每个按钮使用常开瞬时按键：

-   按钮一端接对应 GPIO。
-   按钮另一端接 GND。
-   软件使用 `pinMode(pin, INPUT_PULLUP)`。
-   未按下通常读 HIGH；按下读 LOW。
-   软件必须做消抖，并处理启动时按钮被按住的情况。

  --------------------------------------------------------------------------------------------------------
  按钮              引脚              软件含义                      约束
  ----------------- ----------------- ----------------------------- --------------------------------------
  测试模式          D3                请求进入/退出非动作测试模式   不触发机械动作

  故障复位          D4                请求清除可复位的软件故障      只能在故障原因已排除且条件满足时接受
  --------------------------------------------------------------------------------------------------------

**重要：D3/D4 按钮仅用于普通软件控制。不要把它们标记为"安全急停"。**

## 5. 状态 LED 接线（后续实现时启用）

每颗 LED 串联一个 220 Ω 至 1 kΩ 的电阻：

-   GPIO → 电阻 → LED 长脚（阳极）。
-   LED 短脚（阴极）→ GND。

  LED    引脚   建议显示含义
  ------ ------ --------------------------
  绿色   D10    系统处于待机且监测正常
  黄色   D11    测试模式或需要注意的状态
  红色   D12    软件故障锁定

状态灯只用于提示，不构成安全保护。第一版当前代码仅使用板载 LED
表示软件故障，外接 LED 尚未启用。

## 6. 舵机接口与供电约定（仅预留，当前不要接）

常见舵机线色可能为：

-   红色：正电源（但必须核对型号资料）。
-   棕色/黑色：GND。
-   橙色/黄色/白色：信号。

线色不是可靠的唯一依据，必须核对舵机说明书或标签。

  舵机     信号引脚   电源                               当前状态
  -------- ---------- ---------------------------------- ----------
  舵机 1   D5         独立、稳压、符合该舵机规格的电源   未启用
  舵机 2   D6         同上；按所有舵机的峰值电流选型     未启用
  舵机 3   D9         同上；按所有舵机的峰值电流选型     未启用

电源接线原则：

1.  舵机电源正极接舵机额定正电源，不接 Uno 5V。
2.  舵机电源负极接舵机 GND。
3.  舵机电源 GND 与 Uno GND 共地。
4.  信号线分别接 D5、D6、D9。
5.  初次独立测试时，机械机构应卸载、无弹丸、无储能，并确保舵机不会夹伤人员或带动危险机构。
6.  在电源容量、舵机电压和实际机构风险未确认前，不要同时给多个舵机通电。

## 7. 当前软件配置对应关系

当前 `src/config/config.h` 应保持以下配置与接线一致：

``` cpp
constexpr uint8_t kInfraredPin = 2;
constexpr uint8_t kInfraredActiveLevel = LOW; // 必须根据实测确认
constexpr uint32_t kDebounceMs = 30;
constexpr uint32_t kReportIntervalMs = 500;
```

`kInfraredActiveLevel = LOW`
只是常见模块的初始假设，不是所有模块的通用规则。

## 8. 上电前检查清单

-   [ ] Arduino USB 已拔掉后再接线。
-   [ ] 红外模块的 VCC/GND/OUT 已根据丝印核对。
-   [ ] 模块供电电压已确认。
-   [ ] OUT/DO 接 D2，GND 与 Uno GND 相连。
-   [ ] 没有把舵机电源接到 Uno 5V。
-   [ ] 当前阶段未连接舵机，先验证红外传感器。
-   [ ] 外接 LED 每颗都有串联限流电阻。
-   [ ] 已区分软件故障锁定与实体断电/急停。
-   [ ] 上电后通过串口分别记录无遮挡和遮挡时的原始电平。
